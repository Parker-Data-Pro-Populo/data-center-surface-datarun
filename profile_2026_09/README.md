# September 2026 revision

This directory holds the research, model and section drafts behind the September 1, 2026 revision
of the Black Mountain / Parker County briefing.

## Where the original lives

The June 2026 briefing is **unchanged and still published from `main`**. Nothing on this branch
touches it. Two ways to get back to it:

- `git checkout briefing-2026-06` — an annotated tag on commit `a4b1988`, the June briefing exactly
  as published: the 80% Chapter 312 abatement assumption, the $30M / $364M headline, and the 1 GW
  acreage-implied buildout.
- `git checkout main` — same content, since this revision lives only on `revision-2026-09`.

The revision does not delete the June figures. The $364 million appears in the rebuilt deck as one
labelled cell of the scenario grid — the cell where "1 GW, acreage-implied" meets "80% Chapter 312" —
so a reader can see what was claimed, what it rested on, and why it is no longer the headline.

## Why the revision exists

Residents told the author the site had become misleading. They were right about one thing
specifically: every headline number was generated by an assumed 80% Chapter 312 abatement, and
Parker County has since adopted **Resolution 26-25**, declining abatements for data centers. The
site was describing a scenario the county had formally refused. `STATE_OF_THE_ISSUE_2026-09.md`
documents that finding, the state and local record as of September 1, 2026, and everything that
changed as a result.

## Reproducing the figures

```
cd profile_2026_09 && Rscript RCO_05g_scenarios.R
```

Requires R with `data.table`; reads from `../parker_costs/`. The campaign-finance query needs the
TEC bulk export loaded into a local Postgres database (`tec_finance` schema, `contributions_raw`).

## Known gaps, carried openly

1. The permitted capacity of the Parker plant is not on any public surface. TCEQ's Central Registry
   entry for Registration 179422 has no capacity; the Central File Room returns no documents. The
   75 MW figure is testimony, and is labelled as such. A records request to TCEQ Air Permitting is
   the fix.
2. The site-specific groundwater ceiling needs the Trinity thickness at the tract, from the
   district's Tract Size Requirements Map or its newly commissioned local flow model.
3. UTGCD had not posted the rules text adopted August 27, 2026 as of September 1; the amendments
   are quoted from the proposed-rules document read with the district's signed agenda for that date.
