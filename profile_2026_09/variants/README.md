(`../BALANCE_PASS_2026-09.md`).

henrylee.vote build can restore them without anyone rewriting from memory.

| `STATEMENT.campaign.html` | `../../STATEMENT.html`, now *Standards, methods, and disclosures* |
| `STATEMENT.campaign.md` | `../../STATEMENT.md`, same |

Chart G is not stored here — `../regen_chart_G_2026-09.R` builds either voice from
`RCO_VOICE=neutral` (default) or `RCO_VOICE=campaign`.

**One rule:** these files hold *voice* only. No figure, date, citation or source line may differ
between a variant and the published text. If one does, the variant is wrong.
